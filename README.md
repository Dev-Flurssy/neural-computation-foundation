# Neural Computation Foundations

Welcome to my Neural Computation learning repository.

This repository documents my journey studying **Neural Computation** as part of my university coursework while also exploring concepts beyond the classroom through practical implementations, experiments, visual notes, and supplementary resources.

The goal is to build a strong foundation in neural networks, machine learning fundamentals, and computational intelligence while creating a resource that can help others learn alongside me.

---

## Why This Repository?

As a student taking Neural Computation at university, I wanted a central place to:

- Organize lecture notes and study materials
- Document important concepts in simple language
- Build practical implementations from scratch
- Explore additional resources beyond the classroom
- Track my learning progress over time
- Share knowledge with other learners

Rather than keeping private notes, I decided to make this repository public so it can benefit:

- Students taking Neural Computation courses
- Beginners exploring Artificial Intelligence
- Developers transitioning into Machine Learning
- Senior learners revisiting foundational concepts
- Anyone curious about how neural networks work
