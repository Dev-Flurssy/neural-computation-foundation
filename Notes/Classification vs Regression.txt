CLASSIFICATION

Classification is a machine learning task where the model predicts a category or class.
Output Type: Category

Examples:
• Healthy / Sick
• Spam / Not Spam
• Cat / Dog
• Approved / Rejected

Purpose: Assign an example to one class from a finite set of classes.
When Used: When the target variable is categorical.

Example:
Features:
Age = 45
Weight = 80

Target:
Healthy
Sick

Result: Classification

------------------------------------------------------------
BINARY CLASSIFICATION

Binary Classification is a classification problem with exactly two possible classes.

Notation:
|C| = 2

Examples:
• Healthy / Sick
• Spam / Not Spam
• Fraud / Not Fraud
• Pass / Fail

Purpose: Predict one of two possible outcomes.
When Used: Whenever there are exactly two categories.

Example:
Input: Attendance = 90%
Prediction: Pass

Result: Binary Classification

------------------------------------------------------------
MULTICLASS CLASSIFICATION

Multiclass Classification is a classification problem with three or more possible classes.

Notation:
|C| ≥ 3

Examples:
• Cat / Dog / Bird
• Apple / Banana / Orange
• Normal / AF / RBBB / Other

Purpose: Predict one category from multiple possible classes.
When Used: Whenever there are three or more categories.

Example:
Input: Animal Image
Prediction: Dog

Result: Multiclass Classification

------------------------------------------------------------
REGRESSION

Regression is a machine learning task where the model predicts a numerical value.
Output Type: Number

Notation: y ∈ ℝ

Examples:
• House Price
• Temperature
• Salary
• Energy Consumption

Purpose: Predict a measurable quantity.
When Used: When the target variable is numerical.

Example:

Features:
Size = 120 m²
Bedrooms = 3

Prediction: €250,000

Result: Regression

------------------------------------------------------------
TARGET

The target is the value that the model must predict.
Notation: y

Purpose: Defines the machine learning problem.

Key Rule:
Do not determine the problem type from the inputs.
Determine it from the target.

Examples:

Target: Healthy / Sick
Result: Classification

Target: Temperature = 25.6°C
Result: Regression

------------------------------------------------------------
FEATURES VS TARGET

Features (x): Information supplied to the model.
Target (y): Information the model must predict.

Example:
Features:
• Age
• Weight
• Blood Pressure

Target: Healthy / Sick
Task: Classification

Example:
Features:
• Age
• Weight
• Blood Pressure

Target: Glucose = 126.4
Task: Regression

Same features.
Different target.
Different machine learning problem.

------------------------------------------------------------
CLASSIFICATION VS REGRESSION

Classification: Predicts a category.

Examples:
• Pass / Fail
• Spam / Not Spam
• Cat / Dog

Output: Category

Regression: Predicts a numerical value.

Examples:
• Salary
• Temperature
• House Price

Output: Number

Quick Rule:
Category → Classification
Number → Regression
