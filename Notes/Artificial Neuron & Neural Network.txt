NEURAL COMPUTATION

Neural Computation is the study of how information is processed by neural systems, both biological and artificial.
Its goal is to understand how neurons learn, store information, recognize patterns, and produce intelligent behavior.

------------------------------------------------------------
WHAT IS NEURAL COMPUTATION?

Neural Computation combines:
• Neuroscience (study of the brain)
• Mathematics
• Computer Science

It investigates how networks of neurons process information and solve problems.

------------------------------------------------------------
WHY STUDY NEURAL COMPUTATION?

The human brain can:
• Learn from experience
• Recognize objects
• Understand language
• Make decisions
• Solve complex problems

Neural Computation attempts to explain these abilities and reproduce them in computers.

------------------------------------------------------------
BIOLOGICAL NEURONS

The brain contains billions of neurons.

Each neuron can:
Receive Signals → Process Information → Send Signals to other neurons.

The interaction of many neurons produces intelligent behavior.

------------------------------------------------------------
HOW A BIOLOGICAL NEURON WORKS

Step 1: Receive inputs from other neurons.
Step 2: Combine incoming signals.
Step 3: If the signal is strong enough, the neuron fires.
Step 4: Output is sent to other neurons.

------------------------------------------------------------
ARTIFICIAL NEURON

An Artificial Neuron is the basic building block of a Neural Network.
It is a mathematical model inspired by biological neurons in the human brain.
Its purpose is to receive inputs, process them, and produce an output.

------------------------------------------------------------
SIMPLE DEFINITION

Artificial Neuron = Inputs + Weights + Bias + Activation Function + Output

------------------------------------------------------------
NEURAL NETWORK

A Neural Network is a collection of interconnected artificial neurons that work together to solve problems, 
make predictions, recognize patterns, and learn from data.
It is inspired by the way neurons are connected in the human brain.

------------------------------------------------------------
SIMPLE DEFINITION

Neural Network = Many Artificial Neurons Connected Together

------------------------------------------------------------
PURPOSE OF A NEURAL NETWORK

A Neural Network learns from examples and improves its performance over time.

It can be used to:
• Recognize handwritten digits
• Recognize faces
• Translate languages
• Predict outcomes
• Detect spam emails
• Process speech

------------------------------------------------------------
HOW A NEURAL NETWORK WORKS

Step 1: Receive input data.
Step 2: Pass the data through several neurons.
Step 3: Each neuron performs calculations.
Step 4: The final layer produces the output.

------------------------------------------------------------
BASIC STRUCTURE OF A NEURAL NETWORK

Input Layer → Hidden Layer → Output Layer
Example:

     x1      x2      x3
      \      |      /
       \     |     /
        [ Hidden ]
        [ Layer  ]
            |
            |
        [ Output ]

------------------------------------------------------------
HOW NEURONS WORK TOGETHER

A single neuron can make a simple decision.
Many neurons working together can make complex decisions.

Example:
First Layer: Detects simple features.
Second Layer: Combines these features.
Third Layer: Recognizes complex patterns.
Final Layer: Makes the final prediction.

------------------------------------------------------------
HANDWRITTEN DIGIT EXAMPLE

Suppose we show the network an image of the digit 9.

Input: Pixel values from the image.
Hidden Layers: Detect lines, curves, and shapes.
Output Layer: Decides which digit is present.
Output: 9

------------------------------------------------------------
LEARNING IN A NEURAL NETWORK

Initially:
The weights and biases are random.
The network makes many mistakes.

During training:
• Errors are calculated
• Weights are adjusted
• Biases are adjusted

Over time:
The network becomes more accurate.
This process is called Learning.

KEY COMPONENTS OF A NEURAL NETWORK

• Inputs
• Artificial Neurons
• Weights
• Biases
• Activation Functions
• Outputs

All work together to process information.

------------------------------------------------------------
HOW AN ARTIFICIAL NEURON WORKS

Step 1: Receive inputs.
Example:
x1 = 1
x2 = 0

Step 2: Multiply each input by its weight.
Example:
w1x1
w2x2

Step 3: Add all weighted inputs together.
w3x3 = w1x1 + w2x2

Step 4: Add the bias.
z = w3x3 + b

Step 5: Pass the result through an activation function.
f(z) = Activation function(z)

Step 6: Produce the final output.
y = f(z)
------------------------------------------------------------
STRUCTURE OF AN ARTIFICIAL NEURON

          x1
           \
            \
          x2 ---> [ Neuron ] ---> Output
            /
           /
          x3

Inputs: x1, x2, x3
Weights: w1, w2, w3
Bias: b
Activation Function: Step Function, Sigmoid, ReLU, etc.

------------------------------------------------------------
NEURON FORMULA

Weighted Sum:
z = w1x1 + w2x2 + w3x3 + b

Output:
Output = Activation(z)

------------------------------------------------------------
WHAT ARE INPUTS?

Inputs are the information given to the neuron.

Examples:
• Pixel values in an image
• Temperature readings
• Exam scores
• Sensor data

------------------------------------------------------------
WHAT ARE WEIGHTS?

Weights determine the importance of each input.

Large Weight:
Input has strong influence.

Small Weight:
Input has weak influence.

Example:
Weather Weight = 8
Transport Weight = 2
Weather affects the decision more than transport.

------------------------------------------------------------
WHAT IS BIAS?

Bias helps the neuron adjust its decision.
Think of bias as an extra value that makes it easier or harder for the neuron to activate.

Large Positive Bias:
Neuron activates easily.

Large Negative Bias:
Neuron activates less easily.

------------------------------------------------------------
WHAT IS AN ACTIVATION FUNCTION?

The Activation Function decides the final output.

Common Activation Functions:
• Step Function
• Sigmoid Function
• ReLU Function
• Tanh Function

------------------------------------------------------------
PERCEPTRON AS AN ARTIFICIAL NEURON

The Perceptron is the simplest Artificial Neuron.
Output: 0 or 1

Characteristics:
• Hard decision boundary
• Sudden output changes
• Difficult to train

------------------------------------------------------------
SIGMOID NEURON AS AN ARTIFICIAL NEURON

The Sigmoid Neuron is an improved Artificial Neuron.
Output: Any value between 0 and 1

Characteristics:
• Smooth output
• Easy to train
• Supports learning algorithms

QUESTION 

Suppose we take all the weights and biases in a network of perceptrons, 
and multiply them by a positive constant,  c > 0.
Show that the behaviour of the network doesn't change.

------------------------------------------------------------
ANSWER

Suppose a perceptron computes:
Output = 1 if w·x + b > 0
Output = 0 if w·x + b ≤ 0

The new expression becomes: c(w·x + b)
Since c is positive, multiplying by c does not change whether the value is positive, negative, or zero.

If: w·x + b > 0
then: c(w·x + b) > 0

And if: w·x + b ≤ 0
then: c(w·x + b) ≤ 0

Therefore, every perceptron produces exactly the same output as before.
Since the output of each perceptron remains unchanged, all inputs to later perceptrons also remain unchanged.
Hence, the behaviour of the entire network does not change.

------------------------------------------------------------
QUESTION 

Suppose we have the same setup as the last problem, a network of perceptrons. 
Suppose also that the overall input to the network of perceptrons has been chosen. 
We won't need the actual input value, we just need the input to have been fixed. 
Suppose the weights and biases are such that for the input to any particular perceptron in the network.
Now replace all the perceptrons in the network by sigmoid neurons, and multiply the weights and biases by a positive constant 

(w·x + b) ≠ 0 c > 0. 
Show that in the limit as c → ∞ the behaviour of this network of sigmoid neurons is exactly the same as the network of perceptrons. 
How can this fail when for one of the perceptrons? w⋅ x+b = 0.

------------------------------------------------------------
ANSWER

For a sigmoid neuron, the output is σ(c(w·x+b)). 
If w·x+b > 0, 
then c(w·x+b) → +∞ as c → ∞, and σ(c(w·x+b)) → 1. 
If w·x+b < 0, 
then c(w·x+b) → -∞ and σ(c(w·x+b)) → 0. 

Thus each sigmoid neuron produces the same output as the corresponding perceptron, 
and the entire sigmoid network behaves exactly like the perceptron network.

The argument fails when w·x+b = 0 because c(w·x+b) remains 0 for all c. 
In that case the sigmoid output is σ(0) = 0.5, while the perceptron outputs 0. 
Therefore the two networks may behave differently.
