BACKPROPAGATION

Backpropagation is an algorithm that computes how the loss changes with respect to every weight and bias in a neural network.

Notation:
∂L/∂w
∂L/∂b

Main Idea:
Start from the error at the output layer and move backward through the network.
Purpose: Determine how much each parameter contributed to the final error.

When Used: During training after the loss has been calculated.

------------------------------------------------------------
WHY IS IT CALLED BACKPROPAGATION?

Backpropagation consists of a backward movement of error information through the network.

Forward Pass: Input → Hidden Layer → Output Layer

Computes:
• Activations
• Prediction

Backward Pass: Output Layer → Hidden Layer → Earlier Layers

Computes: 
Gradients

Important:
Backpropagation does NOT reverse the prediction.
It computes derivatives and gradients.

------------------------------------------------------------
COMPLETE TRAINING CYCLE

Step 1: Input data enters the network.
Step 2: Forward propagation computes activations.
Step 3: Prediction is produced.
Step 4: Loss is calculated.
Step 5: Backpropagation computes gradients.
Step 6: Gradient descent updates parameters.
Step 7: Repeat until performance improves.

Flow:
Input → Forward Pass → Prediction → Loss → Backpropagation → Gradients → Update

------------------------------------------------------------
BACKPROPAGATION VS GRADIENT DESCENT

Backpropagation and Gradient Descent are different processes.

Backpropagation:
Purpose: Calculate gradients.
Output:
∂L/∂w
∂L/∂b

Gradient Descent:
Purpose: Use gradients to update parameters.
Weight Update: wnew = wold − η(∂L/∂w)

Memory Rule:
Backpropagation computes gradients.
Gradient Descent uses gradients.

------------------------------------------------------------
CHAIN RULE

The Chain Rule allows us to calculate how one variable affects another through a sequence of operations.

General Form:
y = f(g(x))
dy/dx = (dy/dg)(dg/dx)

Purpose: Track the effect of x on y through intermediate variables.
Why Needed: A loss value depends on weights indirectly through many layers.

------------------------------------------------------------
CHAIN RULE INTUITION

Suppose:
y depends on u
u depends on x

Then:
x affects u
u affects y

Therefore: x affects y

The total effect is:
dy/dx = (dy/du)(du/dx)

Backpropagation repeatedly applies this rule throughout the network.

------------------------------------------------------------
CHAIN RULE EXAMPLE

Given:
u = 2x + 1
y = u²

Find: dy/dx

Step 1: dy/du = 2u
Step 2: du/dx = 2
Step 3:
dy/dx = (dy/du)(du/dx)
dy/dx = (2u)(2)
dy/dx = 4u

Substitute: u = 2x + 1
Final Answer: dy/dx = 4(2x + 1)

------------------------------------------------------------
A NEURON AS A COMPUTATIONAL CHAIN

A neuron consists of multiple connected operations.

Flow:
w → z = wx + b → a = f(z) → L(a)

To find: ∂L/∂w

Apply Chain Rule:
∂L/∂w = (∂L/∂a)(∂a/∂z)(∂z/∂w)

This equation is the mathematical foundation of backpropagation.

------------------------------------------------------------
THREE LOCAL DERIVATIVES

Backpropagation combines three local derivatives.

Loss Derivative: ∂L/∂a
Activation Derivative: ∂a/∂z
Weighted Sum Derivative: ∂z/∂w

Purpose: Convert small local effects into the overall gradient.

------------------------------------------------------------
LOSS FUNCTION

For many introductory examples we use Squared Error Loss.

Formula: L = ½(ŷ − y)²

Where:
ŷ = Prediction
y = Actual Target

Derivative: ∂L/∂ŷ = ŷ − y
Purpose: Measures how far predictions are from targets.

------------------------------------------------------------
WHY USE ½ IN SQUARED ERROR?

Loss:
L = ½(ŷ − y)²

Derivative:
∂L/∂ŷ
= ½ × 2(ŷ − y)
The 2 cancels the ½

Result: ∂L/∂ŷ = ŷ − y
Purpose: Produces cleaner derivatives.

------------------------------------------------------------
SIGMOID ACTIVATION FUNCTION

Formula:
σ(z) = 1 / (1 + e⁻ᶻ)

Produces values between: 0 and 1
Commonly used for binary classification.

------------------------------------------------------------
SIGMOID DERIVATIVE

Derivative:
σ'(z) = σ(z)[1 − σ(z)]

If: a = σ(z)
Then: ∂a/∂z = a(1 − a)

Purpose: Measures how sensitive the activation is to changes in z.

------------------------------------------------------------
SIGMOID DERIVATIVE EXAMPLE

Given: a = 0.8

Compute:
a(1 − a)
= (0.8)(0.2)
= 0.16

Result: σ'(z) = 0.16

------------------------------------------------------------
OUTPUT ERROR TERM

The output error term is written as:
δo
Formula:
δo = (ŷ − y) ŷ(1 − ŷ)

Components:
Prediction Error: ŷ − y
Activation Sensitivity: ŷ(1 − ŷ)

Purpose: Measures loss sensitivity at the output neuron.

------------------------------------------------------------
MEANING OF DELTA (δ)

Delta represents the local error signal of a neuron.

Output Layer:
δo = ∂L/∂zo

Contains:
• Prediction Error
• Activation Sensitivity

Purpose: Used to calculate gradients.

------------------------------------------------------------
OUTPUT WEIGHT GRADIENT

Output Layer Equation:
zo = vh + bo

Derivative: ∂zo/∂v = h
Gradient: ∂L/∂v = δo h

Memory Rule:
Weight Gradient = Error Term × Input

------------------------------------------------------------
OUTPUT BIAS GRADIENT

Output Equation:
zo = vh + bo

Derivative: ∂zo/∂bo = 1 
Therefore: ∂L/∂bo = δo

Reason: Bias enters the equation with coefficient 1.

------------------------------------------------------------
WHY HIDDEN LAYERS ARE HARDER

Output Neuron: Has direct access to target values.
Error is easy to calculate.

Hidden Neuron: Has no target label.
Its contribution must be traced through downstream neurons.

------------------------------------------------------------
HIDDEN LAYER ERROR TERM

Formula:
δh = (vδo) h(1 − h)

Components:
vδo = Downstream Influence
h(1 − h) = Local Sensitivity

Purpose: Determine how much hidden neurons contributed to the final loss.

------------------------------------------------------------
GENERAL HIDDEN LAYER FORM

Formula:
δ(l)
= [(W(l+1))ᵀ δ(l+1)] ⊙ f'(z(l))

Meaning:
(W(l+1))ᵀ = Transmit error backward
δ(l+1) = Next layer error
f'(z(l)) = Local derivative ⊙
= Element-wise multiplication

------------------------------------------------------------
WHY IS THE WEIGHT MATRIX TRANSPOSED?

Forward Pass:
Current Layer → W → Next Layer

Backward Pass:
Next Layer Gradient → Wᵀ → Previous Layer

Purpose: Align dimensions correctly during backpropagation.

------------------------------------------------------------
HIDDEN WEIGHT GRADIENT

Hidden Layer Equation: zh = wx + bh
Derivative: ∂zh/∂w = x
Gradient: ∂L/∂w = δh x

General Form:
∂L/∂W(l) = δ(l)(a(l−1))ᵀ

------------------------------------------------------------
HIDDEN BIAS GRADIENT

Derivative: ∂zh/∂bh = 1
Gradient: ∂L/∂bh = δh

Same principle used at every layer.

------------------------------------------------------------
REPEATING BACKPROP PATTERN

At every layer:
Step 1: Receive downstream gradient.
Step 2: Multiply by local derivative.
Step 3: Compute gradients.
Step 4: Pass error backward.

Backpropagation repeats this process layer by layer.

------------------------------------------------------------
PARAMETER UPDATES

Weights:
wnew = wold − η(∂L/∂w)

Biases:
bnew = bold − η(∂L/∂b)

Where:
η = Learning Rate

Purpose: Move parameters toward lower loss.

------------------------------------------------------------
BIAS UPDATE RULE

Incorrect:
bnew = bold − δ

Correct:
bnew = bold − ηδ

Important: 
Learning rate must be applied to both:
• Weights
• Biases

------------------------------------------------------------
COMPLETE BACKPROPAGATION WORKFLOW

Forward Pass → Prediction → Loss → Output Error Term (δo) → Hidden Error Term (δh) → Gradients → Parameter Updates

Purpose: Train the network by reducing loss.

------------------------------------------------------------
FORWARD VALUES MUST BE STORED

Backpropagation reuses values from the forward pass.

Example:
Stored Hidden Activation: h
Used In:
∂L/∂v = δoh
and h(1 − h)

Purpose: Avoid recalculating activations.

------------------------------------------------------------
WHY DID THE WEIGHTS INCREASE?

Suppose: ∂L/∂w < 0

Update Rule:
wnew = wold − η(∂L/∂w)
Subtracting a negative value becomes addition.

Example:
wnew = 0.5 − (0.1)(−0.02)
wnew = 0.502

Result: Weight increases.

------------------------------------------------------------
LOCAL GRADIENTS VS GLOBAL EFFECT

Local Information:
• Input
• Activation Derivative
• Downstream Gradient

Chain Rule combines them to measure a parameter's total effect on loss.

Purpose: Determine contribution of each parameter to overall error.

------------------------------------------------------------
COMMON MISTAKE 1

Backpropagation does NOT reverse the prediction.

Forward Pass: Produces predictions.
Backward Pass: Produces gradients.

Purpose: Update parameters.

------------------------------------------------------------
COMMON MISTAKE 2

Wrong Sigmoid Derivative

Incorrect: ŷ(1 − y)

Correct: ŷ(1 − ŷ)

Reason: The derivative depends on the sigmoid output itself.

------------------------------------------------------------
COMMON MISTAKE 3

Updating Parameters Too Early

Incorrect Order:
Forward → Loss → Update

Correct Order:
Forward → Loss → All Gradients → Update

Reason: All gradients must be computed before updating parameters.

------------------------------------------------------------
COMMON MISTAKE 4

Prediction Error Is Not The Weight Gradient

Prediction Error: ŷ − y
Weight Gradient: ∂L/∂w

To obtain a weight gradient, the full chain rule must be applied.

------------------------------------------------------------
COMMON MISTAKE 5

Forgetting The Activation Derivative

Incorrect: Incoming Error Only

Correct: Incoming Error × Activation Derivative

Example: 
δ × a(1 − a)

------------------------------------------------------------
TRAINING DATASET TERMINOLOGY

Single Example: One data point.
Mini-Batch: Small group of examples.
Dataset: All training examples.

Backpropagation works the same way for all cases.

------------------------------------------------------------
EPOCH

1 Epoch = One complete pass through the entire training dataset.

Example:
Dataset:
1000 training examples

After processing all 1000 examples once:
1 Epoch Completed

------------------------------------------------------------
WHY REPEAT TRAINING?

One update rarely finds the best parameters.

Process:
Forward Pass → Loss → Backpropagation → Update → Repeat

Repeated updates gradually improve the model.

------------------------------------------------------------
BACKPROPAGATION IN MULTILAYER NETWORKS

Forward:
Input → Hidden Layer 1 → Hidden Layer 2 → Output

Backward:
Output → Hidden Layer 2 → Hidden Layer 1

Key Idea:
At every layer:
Downstream Gradient × Local Derivative
