NEURAL NETWORK ARCHITECTURE

Neural Network Architecture refers to the way neurons are organized and connected within a neural network.

It defines:
• How information enters the network
• How it is processed
• How predictions are produced

------------------------------------------------------------
SIMPLE DEFINITION

Neural Network Architecture = Input Layer + Hidden Layer(s) + Output Layer

------------------------------------------------------------
BASIC STRUCTURE

Input Layer → Hidden Layer(s) → Output Layer
Data always moves through these layers to produce an output.

------------------------------------------------------------
INPUT LAYER

The Input Layer is the first layer of the network.
Its job is to receive data from the outside world.

Examples of inputs:
• Image pixels
• Text
• Audio signals
• Sensor measurements
• Numerical features

The neurons in this layer are called Input Neurons.

------------------------------------------------------------
HIDDEN LAYERS

Hidden Layers lie between the input and output layers.
The neurons in these layers are called Hidden Neurons.

Purpose:
• Process information
• Detect patterns
• Extract features
• Learn relationships in data

A neural network may contain:
• One hidden layer
• Multiple hidden layers

More hidden layers allow the network to learn more complex patterns.

------------------------------------------------------------
OUTPUT LAYER

The Output Layer is the final layer of the network.
Its purpose is to produce the network's prediction.

Examples:
Output = 9
Meaning: The network predicts the digit is 9.
Output = 0.95
Meaning: 95% confidence in a prediction.

The neurons in this layer are called Output Neurons.

------------------------------------------------------------
EXAMPLE: DIGIT RECOGNITION

Goal:
Determine whether an image contains the digit 9.

Input Layer → Receives pixel values
Hidden Layer(s) → Analyzes edges, curves and shapes
Output Layer → Produces final prediction

Example:
Output < 0.5 → Not a 9
Output ≥ 0.5 → Is a 9

------------------------------------------------------------
WHAT DO HIDDEN LAYERS LEARN?

First Hidden Layer
Learns simple features:
• Lines
• Edges
• Curves

Second Hidden Layer
Learns combinations of features:
• Shapes
• Parts of digits

Third Hidden Layer
Learns complex patterns:
• Complete digits
• Objects

------------------------------------------------------------
NETWORK WITH ONE HIDDEN LAYER

Input Layer → Hidden Layer → Output Layer
This is called a 3-layer network.

Layers:
1. Input Layer
2. Hidden Layer
3. Output Layer

------------------------------------------------------------
NETWORK WITH TWO HIDDEN LAYERS

Input Layer → Hidden Layer 1 → Hidden Layer 2 → Output Layer
This is called a 4-layer network.

Layers:
1. Input Layer
2. Hidden Layer 1
3. Hidden Layer 2
4. Output Layer

------------------------------------------------------------
MULTI-LAYER PERCEPTRON (MLP)

A neural network containing one or more hidden layers is commonly called a MLP (Multi-Layer Perceptron)

Structure:
Input Layer → Hidden Layer → Hidden Layer  → Output Layer
MLPs are among the most common neural network architectures.

------------------------------------------------------------
FEEDFORWARD NEURAL NETWORK

A Feedforward Neural Network passes information in only one direction.
Input Layer → Hidden Layer(s) → Output Layer

Information always moves forward.
There are no loops or feedback connections.

------------------------------------------------------------
CHARACTERISTICS OF FEEDFORWARD NETWORKS

• Data moves from input to output
• No feedback loops
• Most common architecture
• Easier to train
• Used in many machine learning tasks

------------------------------------------------------------
WHY NO LOOPS?

If loops existed, a neuron's input could immediately depend on its own output.
This creates circular dependencies that are difficult to compute.

Therefore: Feedforward networks do not contain loops.

------------------------------------------------------------
RECURRENT NEURAL NETWORKS (RNN)

Unlike feedforward networks, RNNs contain feedback connections.

Example:
Neuron A → Neuron B → Neuron C → Neuron A

Previous outputs can influence future predictions.

------------------------------------------------------------
CHARACTERISTICS OF RNNS

• Contain loops
• Have memory
• Remember previous information
• Handle sequential data
• More difficult to train

Applications:
• Speech Recognition
• Language Translation
• Text Generation
• Time Series Forecasting

------------------------------------------------------------
FEEDFORWARD VS RECURRENT NETWORKS

Feedforward Network
• No loops
• Information flows forward only
• Easier to train
• Commonly used

RNN
• Contains loops
• Remembers previous information
• Handles sequences
• More difficult to train

------------------------------------------------------------
DIGIT RECOGNITION EXAMPLE

Suppose an image size is:
64 × 64 pixels

Number of Input Neurons:
64 × 64
= 4096 Input Neurons

Each neuron receives one pixel value.
Pixel values are usually scaled between: 0 and 1

------------------------------------------------------------
NEURAL NETWORK ARCHITECTURES FOR DIFFERENT TASKS

There is NO single neural network architecture that is best for every problem.
Different tasks require different architectures.
Think of architectures as tools:

Hammer → good for nails
Screwdriver → good for screws
Wrench → good for bolts

Similarly:

MLP → tabular data
CNN → images
RNN/LSTM → sequences
Autoencoder → data compression and reconstruction

------------------------------------------------------------
WHY DO WE NEED DIFFERENT ARCHITECTURES?

Different data types have different characteristics.

Images → Spatial Patterns
Text → Sequence & Context
Tabular Data → Features & Attributes
Compressed Data → Feature Extraction

Therefore:
Different Problem → Different Architectures

------------------------------------------------------------
MLP (MULTI-LAYER PERCEPTRON)

MLPs are feedforward neural networks designed for structured data.

Structure:
Input Layer → Hidden Layer → Hidden Layer → Output Layer

------------------------------------------------------------
BEST USES OF MLP

House Price Prediction
Spam Detection
Loan Approval
Customer Churn Prediction
Student Performance Prediction
Medical Diagnosis

MLPs learn relationships between features and variables.

------------------------------------------------------------
LIMITATIONS OF MLP

MLPs do not naturally understand:

• Images
• Spatial patterns
• Sequential data
• Time relationships

For these tasks, specialized architectures perform better.

------------------------------------------------------------
CNN (CONVOLUTIONAL NEURAL NETWORK)

CNNs are designed specifically for image data.
Instead of examining individual pixels separately, they learn visual patterns.

------------------------------------------------------------
WHAT DOES A CNN LEARN?

Layer 1 → Edges
Layer 2 → Corners and Shapes
Layer 3 → Objects and Parts
Final Layer → Image Classification

------------------------------------------------------------
CNN EXAMPLE

Image: Cat

CNN Learns:
Edges → Eyes & Ears → Cat Face → Cat

------------------------------------------------------------
BEST USES OF CNN

Image Classification
Face Recognition
Medical Imaging
Object Detection
Self-Driving Cars
Video Analysis

------------------------------------------------------------
WHY USE CNN?

Example:
100 × 100 Image

Total Pixels:
100 × 100
= 10,000 Inputs

An MLP treats all pixels separately.
A CNN shares filters and learns patterns efficiently.

Result:
Less Computation  → Better Image Recognition

------------------------------------------------------------
RNN (RECURRENT NEURAL NETWORK)

RNNs are designed for sequential data.
They remember previous inputs when processing new information.

------------------------------------------------------------
EXAMPLES OF SEQUENTIAL DATA

Text
Speech
Time Series
Stock Prices
Sensor Data

------------------------------------------------------------
RNN MEMORY EXAMPLE

Sentence: I am drinking a cup of _____
Previous Words → Provide Context → Predict Next Word
Answer: Coffee

RNNs use memory to improve predictions.

------------------------------------------------------------
LSTM (LONG SHORT-TERM MEMORY)

LSTM is an improved version of RNN.
It solves the problem of forgetting important information over long sequences.

------------------------------------------------------------
RNN PROBLEM

Long Sequence → Information Lost → Prediction
This is called: Vanishing Gradient Problem

------------------------------------------------------------
LSTM SOLUTION

LSTM can:
Remember important information longer
Ignore irrelevant information
Preserve long-term context

Therefore LSTMs perform better on lengthy sequences.

------------------------------------------------------------
BEST USES OF RNN/LSTM

Language Translation
Speech Recognition
Chatbots
Text Prediction
Time Series Forecasting
Language Modeling

------------------------------------------------------------
AUTOENCODER

An Autoencoder is a neural network used for:
• Compression
• Reconstruction
• Feature Learning

------------------------------------------------------------
AUTOENCODER STRUCTURE

Input → Encoder → Compressed Representation → Decoder → Reconstructed Output

------------------------------------------------------------
HOW AUTOENCODERS WORK

Original Data → Compress Information → Learn Important Features → Reconstruct Original Data

------------------------------------------------------------
AUTOENCODER EXAMPLE

Original Image
1000 Values → Encoder → 100 Values
(Compressed Representation) → Decoder → 1000 Values
(Reconstructed Image)

------------------------------------------------------------
BEST USES OF AUTOENCODERS

Data Compression
Feature Extraction
Dimensionality Reduction
Noise Removal
Anomaly Detection

------------------------------------------------------------
