BACKPROPAGATION IN MULTILAYER NEURAL NETWORKS

Backpropagation is the learning algorithm used by multilayer neural networks.

It's purpose is to:
• Measure prediction errors
• Determine which weights caused the errors
• Update the weights to improve future predictions

------------------------------------------------------------
SIMPLE DEFINITION

Backpropagation = Forward Pass + Loss Calculation + Backward Pass + Weight Update
The network repeatedly performs these steps until the error becomes very small.

------------------------------------------------------------
THE 4-STEP LEARNING CYCLE

Forward Pass → Loss → Backpropagation → Update Weights → Repeat
This cycle may run thousands of times during training.

------------------------------------------------------------
STEP 1: FORWARD PASS

"Make a Prediction"
The input data enters the network and moves forward through all layers until an output is produced.

Example: Spam Detection
Input Features:
• Contains "FREE" = 1
• Contains Link = 1
• Known Sender = 0

Network Flow:
Input Layer → Hidden Layers → Output
Output = 0.85

Interpretation:
85% probability that the email is spam.
This prediction is the result of the Forward Pass.

Key Points:
• Information flows forward through the network
• Uses current weights to make predictions
• Produces the output value

------------------------------------------------------------
STEP 2: LOSS

"Measure the Error"
The prediction is compared with the correct answer.

Example:
Actual Answer = 1
Prediction = 0.85

Error = 1 − 0.85 = 0.15

A Loss Function calculates how wrong the network is.
Common Loss Functions:
• Mean Squared Error (MSE)
• Binary Cross Entropy
• Categorical Cross Entropy

Goal:
Loss → 0
Smaller loss means better predictions.

Key Points:
• Measures prediction accuracy
• Large loss = poor prediction
• Small loss = good prediction
• Training aims to minimize loss

------------------------------------------------------------
STEP 3: BACKPROPAGATION

"Assign Responsibility"
This is the most important step.
The network works backward through the layers to determine which weights caused the error.

Network Flow:
Output Layer  ←  Hidden Layer  ←  Input Layer
Error flows backward during backpropagation

Backpropagation calculates how much each weight contributed to the loss.

Group Project Analogy:
Imagine a group project receives a poor grade.

The teacher asks:
• Who made the biggest mistake?
• Who made a small mistake?
• Who did fine?

Backpropagation asks these same questions about the network's weights.

------------------------------------------------------------
GRADIENTS

Backpropagation computes values called Gradients.
A gradient tells us:
"If I change this weight slightly, how will the loss change?"

Large Gradient:
• Weight strongly affects the error
• Needs a larger adjustment

Small Gradient:
• Weight has little effect on the error
• Needs a smaller adjustment

Key Points:
• Gradients measure weight importance
• Large gradients indicate highly responsible weights
• Small gradients indicate less important weights
• Backpropagation uses gradients to guide learning

------------------------------------------------------------
STEP 4: UPDATE WEIGHTS

"Adjust Parameters"
After gradients are computed, the network updates the weights.
The goal is to reduce future prediction errors.

Gradient Descent Formula:
New Weight = Old Weight − η(∂L/∂w)

Where:
• L = Loss
• w = Weight
• η (eta) = Learning Rate

Simple Interpretation:
• If a weight causes a lot of error → change it more
• If a weight causes little error → change it less

Key Points:
• Weights are adjusted using gradients
• Updates reduce prediction error
• Learning rate controls update size

------------------------------------------------------------
COMPLETE TRAINING LOOP

The network repeatedly performs:
Forward Pass  ←  Compute Loss  ←  Backpropagation  ←  Update Weights  ← Repeat

Example:
Epoch 1
Epoch 2
Epoch 3
...
Epoch 100

Each cycle usually reduces the loss and improves prediction accuracy.

------------------------------------------------------------
REAL-LIFE ANALOGY: LEARNING BASKETBALL

Forward Pass
You take a shot.

Loss
You see how far the ball misses.

Backpropagation
You determine why:
• Too much force?
• Wrong angle?
• Poor posture?

Update
You make adjustments and try again.
After many attempts, your shooting improves.
This is exactly how a neural network learns.

------------------------------------------------------------
WHY BACKPROPAGATION SOLVES XOR

Earlier we learned:
• A single perceptron cannot solve XOR
• A multilayer neural network can solve XOR

Network Structure:
Inputs → Hidden Layer → Output
The hidden layer learns useful combinations of the inputs.

Backpropagation continuously adjusts the weights in all layers until the network correctly classifies XOR patterns.

Key Point:
• Hidden neurons learn intermediate features
• Backpropagation improves these features over time
• This enables the network to solve XOR

------------------------------------------------------------
EXAM MEMORY TRICK

F-L-B-U:
F = Forward Pass → Make Prediction
L = Loss → Measure Error
B = Backpropagation → Calculate Gradients
U = Update → Adjust Weights

Memory Flow:
F → Predict
L → Measure Error
B → Compute Gradients
U → Update Weights

Repeat until the loss becomes very small.
