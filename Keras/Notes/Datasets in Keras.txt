KERAS DATASETS

Keras provides built-in datasets through:

from keras import datasets

These datasets are automatically downloaded,
preprocessed, and ready for training and testing.

The purpose of keras.datasets is to help developers
focus on building neural networks rather than
collecting and preparing data.

------------------------------------------------------------

WHY USE KERAS DATASETS?

• Easy to Load
• Preprocessed
• Standard Benchmarks
• Useful for Learning
• Ideal for Testing New Models

------------------------------------------------------------

DATASET CATEGORIES

Keras datasets cover three major areas:

1. Image Classification
2. Text Classification/NLP
3. Regression Problems

------------------------------------------------------------

1. MNIST

Problem Type:
• Image Classification

Description:
Handwritten digits from 0 to 9.

Image Type:
• Grayscale

Image Size:
• 28 × 28 pixels

Classes:
• 10

Training Samples:
• 60,000

Testing Samples:
• 10,000

Applications:
• Beginner CNN Projects
• Digit Recognition

Load Dataset:

from keras.datasets import mnist

(x_train, y_train), (x_test, y_test) = mnist.load_data()

------------------------------------------------------------

4. CIFAR-100

Problem Type:
• Fine-Grained Image Classification

Description:
Advanced version of CIFAR-10.

Image Type:
• RGB

Image Size:
• 32 × 32 pixels

Classes:
• 100

Superclasses:
• 20

Training Samples:
• 50,000

Testing Samples:
• 10,000

Applications:
• Advanced CNN Models
• Fine-Grained Recognition

Load Dataset:

from keras.datasets import cifar100

(x_train, y_train), (x_test, y_test) = cifar100.load_data(
    label_mode='fine'
)
