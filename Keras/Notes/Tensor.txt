TENSORS

Tensors are the fundamental data structures used in Deep Learning and Artificial Intelligence.

------------------------------------------------------------

WHAT ARE TENSORS?

A tensor is a multidimensional array used to store and process data efficiently.

• Scalar = 0D Tensor (single value)
• Vector = 1D Tensor (list of values)
• Matrix = 2D Tensor (rows and columns)
• Higher-Dimensional Array = 3D, 4D, or more dimensions

Tensors can represent:
• Images
• Videos
• Text
• Audio
• Time-Series Data
• Machine Learning Datasets

------------------------------------------------------------

WHY STUDY TENSORS?

Tensors allow us to:
• Store large amounts of data efficiently
• Perform fast mathematical computations
• Train deep learning models
• Utilize GPUs and TPUs
• Scale AI applications
• Process massive datasets

Nearly every modern AI system uses tensors.

============================================================

WHY ARE TENSORS IMPORTANT?

As Deep Learning models became larger, traditional computing became too slow.

Tensors solve this problem by:

• Supporting parallel computation
• Working efficiently on GPUs and TPUs
• Handling millions of parameters
• Improving memory efficiency
• Speeding up model training

Without tensors, modern deep learning would not be practical.

------------------------------------------------------------

DIMENSIONS OF A TENSOR

0D Tensor (Scalar)
A single value.

Example:
5

1D Tensor (Vector)
A list of values.

Example:
[1, 2, 3, 4]

2D Tensor (Matrix)
Rows and columns.

Example:
[[1, 2, 3],
 [4, 5, 6]]

3D Tensor
A collection of matrices.

Example:
[[[1,2],[3,4]],
 [[5,6],[7,8]]]

Higher-dimensional tensors are commonly used in images, videos, NLP, and deep learning.

------------------------------------------------------------

TENSORS IN TENSORFLOW

TensorFlow uses tensors as its primary data structure.

TensorFlow can:
• Create tensors
• Manipulate tensors
• Perform mathematical operations
• Calculate gradients automatically
• Train neural networks
• Run computations on CPUs, GPUs, and TPUs

------------------------------------------------------------

TENSORS VS NUMPY ARRAYS

Similarities:
• Store multidimensional data
• Support mathematical operations
• Support broadcasting
• Support indexing and slicing
• Easy conversion between each other

NumPy Arrays:
• CPU-focused
• Mutable by default
• No automatic differentiation
• Used for numerical computing

TensorFlow Tensors:
• GPU and TPU optimized
• Usually immutable
• Support automatic differentiation
• Designed for deep learning
• Support graph optimization

------------------------------------------------------------

GPU SUPPORT

CPUs contain a few powerful cores.
GPUs contain thousands of smaller cores.
Tensor operations run efficiently on GPUs because many calculations can execute simultaneously.
This greatly accelerates deep learning training.

------------------------------------------------------------

AUTOMATIC DIFFERENTIATION

Automatic Differentiation automatically computes gradients needed for backpropagation.

Benefits:
• Faster training
• Automatic gradient calculation
• Easier optimization
• Reduced programming complexity

TensorFlow tensors support Automatic Differentiation while NumPy arrays do not.

------------------------------------------------------------

EAGER EXECUTION

Eager Execution allows TensorFlow operations to execute immediately.

Benefits:
• Easier debugging
• Faster experimentation
• Similar behavior to NumPy

------------------------------------------------------------

BROADCASTING

Broadcasting allows tensors with different shapes to perform arithmetic operations.

Example:
[1, 2, 3] + 3

Result: [4, 5, 6]

Broadcasting works when:
• Dimensions are equal
• One dimension equals 1

Otherwise, TensorFlow raises a broadcasting error.

BASIC TENSOR OPERATIONS

TensorFlow provides built-in operations for creating, modifying, and manipulating tensors.

------------------------------------------------------------

CREATING TENSORS

Constant Tensor (fixed values):
• tf.constant()

Variable Tensor (modifiable values):
• tf.Variable()

Example:
tensor_const = tf.constant([[1, 2], [3, 4]])
tensor_var = tf.Variable([[1, 2], [3, 4]])

============================================================

MATHEMATICAL OPERATIONS

TensorFlow supports element-wise mathematical operations.

Common operations:
• Addition → tf.add()
• Subtraction → tf.subtract()
• Multiplication → tf.multiply()
• Division → tf.divide()

Example:
tensor_add = tf.add(tensor_const, tensor_var)

------------------------------------------------------------

RESHAPING TENSORS

Reshaping changes the tensor shape while keeping the same number of elements.

Why reshape?
• Prepare data for neural networks
• Match layer requirements
• Organize data efficiently

Example:
Original Shape = (2, 3)

[[1, 2, 3],
 [4, 5, 6]]

New Shape = (3, 2)
[[1, 2],
 [3, 4],
 [5, 6]]

Function:
• tf.reshape()

------------------------------------------------------------

FLATTENING TENSORS

Flattening converts a tensor into a one-dimensional tensor.

Example:
Original Shape = (2, 3)
New Shape = (6,)

Function:
• tf.reshape(tensor, [-1])

Common Use:
• Connecting Convolutional Layers to Dense Layers

------------------------------------------------------------

ADDING DIMENSIONS

Sometimes models require extra dimensions.

Example:
Original Shape = (2, 3)
New Shape = (1, 2, 3)

Function:
• tf.expand_dims()

Common Use:
• Adding Batch Dimensions
• Broadcasting Compatibility

------------------------------------------------------------

REMOVING DIMENSIONS

Dimensions with size 1 can be removed.

Example:
Original Shape = (2, 1)
New Shape = (2,)

Function:
• tf.squeeze()

Common Use:
• Cleaning Tensor Shapes
• Post-processing Results

------------------------------------------------------------

SEQUENCE DATA RESHAPING

Used frequently in RNNs, LSTMs, and Sequence Models.

Example Shape:
(batch_size, time_steps, features)

Example:
(1, 2, 3)

Means:
• 1 Batch
• 2 Time Steps
• 3 Features

------------------------------------------------------------

IMAGE CHANNELS

Images contain channels that store color information.

RGB Image:
• Red Channel
• Green Channel
• Blue Channel

Total Channels = 3
Common Image Shape:
(height, width, channels)

Example:
(224, 224, 3)

------------------------------------------------------------

CHANNEL LAST FORMAT

Image Format: (height, width, channels)

Example:
(224, 224, 3)
Used by TensorFlow and Keras by default.

------------------------------------------------------------

CHANNEL FIRST FORMAT

Image Format: (channels, height, width)

Example:
(3, 224, 224)
Used by some Deep Learning frameworks.

------------------------------------------------------------

TRANSPOSING TENSORS

Transposing rearranges tensor dimensions.

Function:
• tf.transpose()

Example:
Original Tensor:
[[1, 2, 3],
 [4, 5, 6]]

Shape: (2, 3)
After: tf.transpose(tensor, perm=[1,0])

Result:
[[1, 4],
 [2, 5],
 [3, 6]]

New Shape: (3, 2)

Common Use:
• Switching Channel Orders
• Rearranging Data Dimensions

============================================================

AUTOMATIC DIMENSION CALCULATION

TensorFlow can automatically calculate one dimension.

Example:

tf.reshape(tensor, [3, -1, 1])

Here:

• 3 = Fixed First Dimension
• -1 = Automatically Calculated
• 1 = Fixed Last Dimension

Benefits:

• Easier Reshaping
• Less Manual Calculation
• Reduces Errors

============================================================

PARALLELISM IN TENSORFLOW

TensorFlow is designed for parallel computation.

Best Practice:

Use TensorFlow's built-in operations instead of manual loops.

Good:

• tf.matmul()
• tf.add()
• tf.multiply()

Avoid:

• Manual for-loops for tensor calculations

Built-in TensorFlow operations are heavily optimized for:

• CPUs
• GPUs
• TPUs

============================================================

BATCH MATRIX MULTIPLICATION

TensorFlow can perform multiple matrix multiplications simultaneously.

Function:

• tf.matmul()

Benefits:

• Faster Training
• Better GPU Utilization
• Parallel Processing Across Batches
