NEURON INITIALIZATION, NETWORK LAYERS, LOSS FUNCTIONS & OPTIMIZERS

------------------------------------------------------------

WHAT IS NEURON INITIALIZATION?

Before a neural network can start learning, its weights and biases must be assigned initial values.
This process is called Initialization.

Initialization helps:
• Start the learning process
• Prevent poor training performance
• Improve convergence speed
• Reduce training instability
• Improve deep network performance

Poor initialization can cause training to fail completely.

------------------------------------------------------------

WHY IS INITIALIZATION IMPORTANT?

Neural networks learn by updating weights.

If weights start with poor values:
• Learning becomes slow
• Gradients may vanish
• Gradients may explode
• Neurons may learn identical features
• Model accuracy may suffer

Good initialization helps the network learn efficiently.

------------------------------------------------------------

DEFAULT INITIALIZATION IN KERAS

For most layers such as:
• Dense Layers
• Convolution Layers (CNN)
• Recurrent Layers (RNN)

Keras uses:
• Glorot Uniform Initialization
• Also known as Xavier Initialization

Biases are usually initialized to:
• Zero

These defaults work well for many deep learning problems.

------------------------------------------------------------

COMMON INITIALIZATION METHODS

The most popular initialization methods are:

• Zero Initialization
• Random Initialization
• Xavier (Glorot) Initialization
• He Initialization
• Orthogonal Initialization

------------------------------------------------------------

ZERO INITIALIZATION

All weights are set to zero.

Example:
w₁ = 0
w₂ = 0
w₃ = 0

Advantages:
• Extremely simple

Disadvantages:
• All neurons learn the same thing
• Network symmetry is not broken
• Learning becomes ineffective

Generally not recommended.

------------------------------------------------------------

RANDOM INITIALIZATION

Weights are assigned random values.

Example:
w₁ = 0.12
w₂ = -0.07
w₃ = 0.31

Advantages:
• Breaks symmetry
• Allows meaningful learning

Disadvantages:
• Large values may cause exploding gradients
• Small values may cause vanishing gradients

The randomness must be carefully controlled.

------------------------------------------------------------

XAVIER (GLOROT) INITIALIZATION

One of the most widely used initialization methods.

Purpose:
• Maintain stable signal flow
• Keep gradient sizes balanced
• Improve training stability

Best used with:
• Sigmoid
• Tanh

Advantages:
• Faster convergence
• Better stability
• Reduced gradient problems

Keras often uses Xavier Initialization by default.

------------------------------------------------------------

HE INITIALIZATION

He Initialization is specifically designed for ReLU-based networks.

Purpose:
• Maintain larger signal variance
• Improve ReLU performance
• Prevent information loss

Best used with:
• ReLU
• Leaky ReLU

Advantages:
• Excellent performance in deep networks
• Faster training
• Stable gradients

------------------------------------------------------------

ORTHOGONAL INITIALIZATION

Weights are initialized using orthogonal matrices.

Purpose:
• Preserve signal strength across layers
• Improve deep network stability

Advantages:
• Useful for deep architectures
• Often used in recurrent networks

------------------------------------------------------------

CHOOSING AN INITIALIZATION METHOD

General Guidelines:
• Xavier → Sigmoid and Tanh
• He → ReLU and Leaky ReLU
• Orthogonal → Deep and Recurrent Networks
• Random → General-purpose
• Zero → Usually avoid

There is no universally perfect initializer.
Experimentation is often necessary.

------------------------------------------------------------

WHAT ARE NETWORK LAYERS?

Neural networks are organized into layers.
Layers process information step by step.

Basic structure:
Input Layer
↓
Hidden Layer(s)
↓
Output Layer

This arrangement is called a Network Architecture.

------------------------------------------------------------

WHY USE LAYERS?

Layers allow the network to:
• Learn simple patterns first
• Learn complex patterns later
• Build hierarchical representations
• Solve difficult problems efficiently

This hierarchy is what enables deep learning.

------------------------------------------------------------

TYPES OF NETWORK LAYERS

The basic neural network contains:
• Input Layer
• Hidden Layer(s)
• Output Layer

------------------------------------------------------------

INPUT LAYER

The input layer receives raw data.

Examples:
• Image pixels
• Sound recordings
• Text features
• Numerical measurements

Responsibilities:
• Receive information
• Pass information forward

The input layer does not usually perform learning.

------------------------------------------------------------

HIDDEN LAYERS

Hidden layers perform computations.

Responsibilities:
• Extract features
• Learn patterns
• Build representations

Examples:

Image Processing:
Hidden Layers Learn:
• Edges
• Shapes
• Objects
• Faces

Text Processing:
Hidden Layers Learn:
• Words
• Meanings
• Context
• Sentiment

Most learning occurs inside hidden layers.

------------------------------------------------------------

OUTPUT LAYER

The output layer produces the final prediction.

Examples:

Binary Classification:
Output: Cat or Not Cat

Multi-Class Classification:
Output: Digits 0-9

Regression:
Output: Predicted House Price

------------------------------------------------------------

FEEDFORWARD NETWORK

The simplest neural network architecture is called a Feedforward Network.

Data flows only in one direction:
Input
→ Hidden Layer
→ Output

Characteristics:
• Simple design
• Easy to understand
• Foundation of deep learning

In Keras, feedforward layers are created using: Dense()

------------------------------------------------------------

WHAT ARE WEIGHTS?

Connections between neurons contain weights.

A weight determines:
• The importance of an input
• How strongly neurons influence one another

Large Weight: Important connection
Small Weight: Less important connection
Zero Weight: No influence

Weights are adjusted during training.

------------------------------------------------------------

DEAD NEURONS

A neuron that consistently outputs zero becomes inactive.

Characteristics:
• No contribution to learning
• No influence on predictions

Such neurons are called: Dead Neurons
This commonly occurs with ReLU activation.

------------------------------------------------------------

LEARNING IN A FEEDFORWARD NETWORK

The learning process follows:
Step 1: Receive Input
Step 2: Make Prediction
Step 3: Compare Prediction with Actual Output
Step 4: Calculate Error
Step 5: Update Weights
Step 6: Repeat

Over time:
Error ↓
Accuracy ↑

------------------------------------------------------------

THREE IMPORTANT COMPONENTS OF LEARNING

A neural network depends heavily on:
• Activation Function
• Loss Function
• Optimizer

Together they determine how well the network learns.

------------------------------------------------------------

WHAT IS A LOSS FUNCTION?

A loss function measures how wrong a prediction is.

Purpose:
• Quantify prediction error
• Guide learning
• Provide feedback

Smaller Loss: Better prediction
Larger Loss: Worse prediction
The network's goal is to minimize loss.

------------------------------------------------------------

WHY DO WE NEED A LOSS FUNCTION?

After making a prediction, the network needs to know: "How far am I from the correct answer?"
The loss function provides this information.

Without a loss function:
• No error measurement
• No learning
• No weight updates

------------------------------------------------------------

TYPES OF LOSS FUNCTIONS

There are three major categories:
• Regression Losses
• Probabilistic Losses
• Hinge Losses

The selection depends on the problem type.

------------------------------------------------------------

REGRESSION LOSS FUNCTIONS

Used when predicting numerical values.

Examples:
• House prices
• Sales forecasts
• Stock prices
• Temperatures

Popular Regression Losses:
• Mean Squared Error (MSE)
• Mean Absolute Error (MAE)

------------------------------------------------------------

MEAN SQUARED ERROR (MSE)

The most popular regression loss function.
Purpose: Measures the average squared difference between actual and predicted values.

Formula: MSE = Average[(Actual − Predicted)²]

Characteristics:
• Always positive
• Punishes large errors heavily
• Zero means perfect prediction

Example:
Actual: [10.2, 11, 12.5, 1, -6.5, 0]
Predicted: [9.9, 12.2, 12.5, 0, 1, 1]
MSE: 9.963333

Interpretation: Lower MSE means better predictions.

------------------------------------------------------------

COSINE SIMILARITY

Cosine Similarity measures similarity between vectors.

Commonly used in:
• Natural Language Processing
• Recommendation Systems
• Text Analysis
• Semantic Search

Purpose: Determine how similar two vectors are.
Output Range: -1 to 1

------------------------------------------------------------

INTERPRETING COSINE SIMILARITY

Value = 1
• Identical direction
• Maximum similarity

Value = 0
• Unrelated vectors

Value = -1
• Opposite direction
• Maximum dissimilarity

------------------------------------------------------------

COSINE SIMILARITY EXAMPLE

Sentence 1: "Humpty Dumpty sat on a wall"
Sentence 2: "Humpty Dumpty had a great fall"

After converting words into vectors:
Cosine Similarity measures how closely the sentences are related.
The larger the value, the more similar the meanings.

------------------------------------------------------------

WHAT IS AN OPTIMIZER?

The optimizer improves the network after every prediction.

Responsibilities:
• Update weights
• Reduce loss
• Improve accuracy

Without an optimizer:
• The network cannot improve
• Learning stops completely

------------------------------------------------------------

HOW DOES AN OPTIMIZER WORK?

After loss is calculated:
1. Measure Error
2. Calculate Gradients
3. Update Weights
4. Repeat

This process gradually improves predictions.

------------------------------------------------------------

BACKPROPAGATION

Backpropagation is the algorithm used to move error information backward through the network.

Responsibilities:
• Calculate gradients
• Determine weight updates
• Support optimization

Backpropagation enables learning.

------------------------------------------------------------

GRADIENT DESCENT

Gradient Descent is the most fundamental optimization technique.
Goal: Find weights that minimize loss.

Process:
• Compute Loss
• Compute Gradient
• Update Weights
• Repeat

Over Time:
Loss ↓
Accuracy ↑

------------------------------------------------------------

OPTIMIZER AND LOSS FUNCTION RELATIONSHIP

Loss Function: Measures Error
Optimizer: Reduces Error

Simple Analogy:
Loss Function = Teacher grading an exam
Optimizer = Student improving after feedback
Together they enable learning.
